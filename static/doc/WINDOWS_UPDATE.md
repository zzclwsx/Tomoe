# Windows 便携版更新

首次安装由使用者自行选择目录并解压 ZIP，运行 `tomoe.exe`。
程序可以位于 D 盘等自选位置。设置、历史、规则和日志继续保存在原应用数据目录，
不会随程序更新而移动；已设置的番剧下载目录也保持不变。

## 旧版首次升级

1.0.0 / 1.0.1 内置的旧更新器只会下载、校验并打开 ZIP。
需要先关闭软件，把 1.0.2 的完整内容解压覆盖到原程序目录，再启动 `tomoe.exe`。
不能只替换 EXE，必须同时更新 `data`、DLL 等完整文件。
完成这一次手动升级后，后续版本才会使用原地更新功能。

## 原地更新流程

1. 从本仓库 Release 下载更新 ZIP 到系统临时目录的 `Tomoe/updates`。
2. 验证 GitHub 资产提供的 SHA-256；缺少或不匹配时不执行更新。
3. 默认目标为当前运行的 `tomoe.exe` 所在目录。目录不可写时可选择空目录或已有同映目录。
   选择其他位置后，旧程序目录保留，原快捷方式需由使用者调整。
4. 启动隐藏的 Windows PowerShell 更新助手。路径通过 JSON 文件传递，不拼接成命令。
5. 助手再次校验 ZIP，解包并检查路径、必要文件、程序身份、目录权限和文件冲突。
   完成准备前，主程序不会退出，也不会覆盖旧文件。
6. 准备成功且操作未取消时，主程序写入安装请求并退出。助手等待该进程完全退出后才替换文件。
7. 备份所有将覆盖的文件，复制新版文件，再从目标目录启动新版。
8. 更新成功后删除临时解包和备份、大体积更新 ZIP，保留小体积日志及结果。

## 失败与取消

- 下载、校验、解包或权限检查失败：主程序保留运行，可选择手动解压覆盖。
- 取消准备：没有安装请求，即使之后退出主程序，助手也不会安装。
- 文件占用或复制失败：重试后恢复已有文件、删除本次新建的文件，不删除目录内的其他文件。
- 启动立即失败：尝试恢复旧版，再从原来的程序目录启动。
- 恢复未完成：保留临时工作目录中的 `backup`、`backup.json` 和 `update.log`，错误窗口显示位置，供维护者恢复。

更新不申请管理员权限。PowerShell 被系统策略禁用时保留手动解压途径。
运行超过短暂启动检查后才发生的程序崩溃，不属于自动回滚范围。

## 维护与验证

更新助手随 Flutter 资源 `assets/update/windows_update.ps1` 打包，兼容 Windows PowerShell 5.1。
下载来源、版本比较、SHA-256 沿用应用更新器；更新助手只负责检查、替换和恢复。
路径拒绝 ZIP 越界、大小写重复路径、链接、设备文件名及磁盘根目录。
递归清理只针对经过边界检查的临时工作目录；程序目录只修改安装包内对应文件。

`test/windows_portable_update_test.dart` 在隔离目录使用真实 PowerShell、ZIP 与进程，
验证旧进程退出前不改文件、中文和特殊字符路径、重启、其他目录安装、校验失败、
缺少文件、重复路径、ZIP 越界、取消及文件占用后的回滚。
